# ♛ Neon Checkers

Русские шашки в браузере: неоновый интерфейс, игра против компьютера или вдвоём.
Один файл `index.html`, без зависимостей и сборки — просто откройте его.

## Возможности
- Полные правила русских шашек: обязательное взятие, серии ударов, «летающие» дамки, превращение в дамку по ходу боя
- Компьютерный соперник (minimax + alpha-beta), три уровня сложности
- Режим «вдвоём» на одном экране
- Отмена хода, подсветка обязательных ударов и пошаговый выбор маршрута
- Анимации, адаптивная вёрстка (телефон и компьютер)

## Запуск
Откройте `index.html` в браузере. Для онлайн-версии включите GitHub Pages:
**Settings → Pages → Branch: main / root**.
