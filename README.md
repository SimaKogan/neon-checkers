# ♛ Neon Checkers

Russian draughts in your browser with a neon UI. Play against the computer or a friend.
A single `index.html` file, no dependencies, no build step: just open it.

**Languages:** English · Русский · עברית (with right-to-left layout)

## Features
- Full Russian draughts rules: mandatory capture, multi-jumps, flying kings, promotion mid-capture
- Computer opponent (minimax + alpha-beta pruning), three difficulty levels
- Two-player mode on one screen
- Undo, highlighted forced captures, step-by-step route selection
- Animations and a responsive layout (phone and desktop)

## Run
Open `index.html` in a browser, or enable GitHub Pages
(**Settings → Pages → Branch: main / root**) to play online.
